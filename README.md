# coast-site

Coast App 的对外页面，托管在 GitHub Pages。

- https://eatlei.github.io/coast-site/ — 首页（产品介绍 / 定价 / FAQ，中英切换）
- https://eatlei.github.io/coast-site/privacy.html — 隐私政策
- https://eatlei.github.io/coast-site/changelog.html — 更新日志

纯静态，无构建。`assets/` 里的 `screen-*.webp` 是从 App Store 营销图
（FIRE 仓库 `app-store-fixed/zh`）裁出的手机屏幕，偏移 (140, 500)、尺寸 962×2084，
压成 640px 宽 webp；`icon.png` 取自 App Store 的应用图标。
